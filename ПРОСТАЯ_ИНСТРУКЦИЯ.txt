🎯 ПРОСТАЯ ИНСТРУКЦИЯ ДЛЯ ЗАГРУЗКИ И ЗАПУСКА

ШАГ 1: НАЙТИ ПАПКУ workspace В CURSOR
=====================================
1. Посмотрите на левую панель в Cursor (боковая панель с файлами)
2. Найдите папку с названием "workspace" 
3. Если не видите - нажмите на значок папки в левой панели

ШАГ 2: ЗАГРУЗИТЬ АРХИВ
======================
Способ A (перетаскивание):
- Откройте папку с вашим архивом на компьютере
- Перетащите ZIP файл в папку workspace в Cursor
- Отпустите файл

Способ B (через меню):
- Щелкните ПРАВОЙ кнопкой по папке workspace
- Выберите "Upload Files" или "Загрузить файлы"
- Выберите ваш ZIP архив
- Нажмите "Открыть"

ШАГ 3: ПРОВЕРИТЬ ЧТО АРХИВ ЗАГРУЗИЛСЯ
====================================
- В папке workspace должен появиться ваш ZIP файл
- Например: "организации.zip" или "мои_файлы.zip"

ШАГ 4: ЗАПУСТИТЬ ОБРАБОТКУ
==========================
1. Откройте терминал в Cursor:
   - Меню Terminal → New Terminal
   - Или нажмите Ctrl+` (Ctrl + обратная кавычка)

2. В терминале введите команду:
   python3 universal_processor.py ИМЯ_ВАШЕГО_АРХИВА.zip
   
   Например:
   python3 universal_processor.py организации.zip

3. Нажмите Enter

ШАГ 5: ПОЛУЧИТЬ РЕЗУЛЬТАТ
========================
- Скрипт создаст файл "ИТОГ.xlsx" в папке workspace
- Этот файл будет содержать все организации без дубликатов
- Веб-адреса будут проверены и исправлены

ВАЖНО:
======
- Замените "ИМЯ_ВАШЕГО_АРХИВА.zip" на реальное имя вашего файла
- Все команды вводятся в терминале Cursor
- Если что-то не работает - напишите мне!

АЛЬТЕРНАТИВА (если нет архива):
===============================
1. Создайте папку "мои_файлы" в workspace
2. Загрузите туда все ваши .xlsx файлы
3. Запустите: python3 universal_processor.py мои_файлы
