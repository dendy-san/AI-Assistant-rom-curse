# 📦 Обработка архивов с Excel файлами организаций

## 🎯 Быстрый старт

**Просто запустите с вашим архивом:**
```bash
python3 universal_processor.py ваш_архив.zip
```

## 📋 Что поддерживается

### Форматы архивов:
- ✅ **ZIP** (.zip) - рекомендуется, работает без дополнительных программ
- ✅ **RAR** (.rar) - требует `unrar` или библиотеку `rarfile`
- ✅ **7-Zip** (.7z) - требует `7z` или библиотеку `py7zr`
- ✅ **TAR** (.tar, .tar.gz, .tar.bz2) - работает встроенными средствами

### Форматы Excel:
- ✅ **.xlsx** (рекомендуется)
- ✅ **.xls** (старый формат)

## 🚀 Способы использования

### 1. Универсальный процессор (РЕКОМЕНДУЕТСЯ)
```bash
# Автоматически определяет тип входных данных
python3 universal_processor.py организации.zip
python3 universal_processor.py папка_с_файлами/
python3 universal_processor.py single_file.xlsx

# С указанием папки для результата
python3 universal_processor.py архив.zip /путь/для/результата
```

### 2. Специально для ZIP архивов
```bash
# Простой и быстрый для ZIP
python3 simple_archive_processor.py организации.zip
```

### 3. Полнофункциональный архивный процессор
```bash
# Поддерживает все форматы архивов
python3 process_archive.py архив.rar
python3 process_archive.py файлы.7z
```

## 📁 Структура архива

Ваш архив может содержать:
```
организации.zip
├── ольгинка + 3км.xlsx
├── другой_регион.xlsx
├── подпапка/
│   ├── еще_файлы.xlsx
│   └── дополнительные.xlsx
└── любые_другие.xlsx
```

**Скрипт автоматически:**
- Найдет все Excel файлы в архиве (включая вложенные папки)
- Извлечет их во временную директорию
- Обработает и объединит в один файл
- Удалит временные файлы после обработки

## 🔧 Установка зависимостей

### Минимальные (для ZIP):
```bash
pip install pandas openpyxl requests
```

### Полные (для всех форматов):
```bash
pip install pandas openpyxl requests rarfile py7zr
```

### Системные программы (альтернатива):
```bash
# Ubuntu/Debian
sudo apt install unrar p7zip-full

# CentOS/RHEL
sudo yum install unrar p7zip
```

## 📝 Что делает скрипт

1. **Извлечение архива** во временную директорию
2. **Поиск Excel файлов** рекурсивно по всем папкам
3. **Автоматическое определение** колонок с организациями и сайтами
4. **Валидация веб-адресов** (невалидные → "---")
5. **Удаление дубликатов** с сохранением записей с валидными сайтами
6. **Сохранение результата** в "ИТОГ.xlsx"
7. **Очистка временных файлов**

## ❗ Важные особенности

- **Дубликаты**: При совпадении названий организаций сохраняется запись с валидным сайтом
- **Безопасность**: Все временные файлы удаляются после обработки
- **Память**: Обработка происходит поэтапно для экономии памяти
- **Логирование**: Подробные логи процесса с статистикой

## 🆘 Решение проблем

### Архив не открывается:
```bash
# Проверьте целостность архива
unzip -t архив.zip
```

### Нет прав доступа:
```bash
# Дайте права на выполнение
chmod +x *.py
```

### Не установлены зависимости:
```bash
# Установите через pip
pip install --break-system-packages pandas openpyxl requests
```

### Много файлов в архиве:
- Скрипт обработает все Excel файлы автоматически
- Большие архивы могут требовать больше времени
- Следите за логами для контроля прогресса

## 📞 Поддержка

При возникновении проблем проверьте:
1. ✅ Архив не поврежден
2. ✅ В архиве есть файлы .xlsx или .xls
3. ✅ Установлены все зависимости Python
4. ✅ Достаточно места на диске для временных файлов
