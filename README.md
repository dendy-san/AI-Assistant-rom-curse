# Обработка Excel файлов с организациями

## Описание
Скрипт для объединения нескольких Excel файлов с данными об организациях в один файл с удалением дубликатов и проверкой валидности веб-адресов.

## Функции
- ✅ Чтение всех Excel файлов из указанной директории
- ✅ Автоматическое определение колонок с названиями организаций и веб-сайтами  
- ✅ Валидация веб-адресов (невалидные заменяются на "---")
- ✅ Удаление дубликатов организаций с сохранением записей с валидными сайтами
- ✅ Сохранение результата в файл ИТОГ.xlsx

## Использование

### Вариант 1: Копирование файлов в рабочую директорию
```bash
# Создайте директорию и скопируйте туда ваши Excel файлы
mkdir /workspace/excel_files
# Скопируйте файлы типа "ольгинка + 3км.xlsx" в эту директорию
# Затем запустите скрипт
python3 process_excel_files.py /workspace/excel_files
```

### Вариант 2: Указание пути к вашим файлам
```bash
python3 process_excel_files.py "путь/к/вашим/файлам"
```

### Вариант 3: Для Windows (если запускаете локально)
```bash
python3 process_excel_files.py "d:\\001\\Kursis\\Kurs_from_Cursor\\Организации\\00"
```

## Требования
- Python 3.6+
- pandas >= 1.5.0
- openpyxl >= 3.0.0
- requests >= 2.25.0

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Особенности работы

1. **Удаление дубликатов**: При наличии нескольких записей одной организации, сохраняется запись с валидным веб-адресом (если есть)

2. **Валидация URL**: 
   - Проверяется корректность формата URL
   - Добавляется http:// если протокол не указан
   - Невалидные адреса заменяются на "---"

3. **Автоматическое определение колонок**: 
   - Ищет колонки с названиями организаций по ключевым словам
   - Ищет колонки с веб-адресами по ключевым словам

4. **Логирование**: Подробные логи процесса обработки с статистикой
