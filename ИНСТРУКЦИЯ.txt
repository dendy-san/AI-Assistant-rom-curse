ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ СКРИПТА ОБРАБОТКИ EXCEL ФАЙЛОВ
================================================================

НАЗНАЧЕНИЕ:
Скрипт объединяет все Excel файлы из указанной директории в один файл,
удаляя дубликаты организаций и проверяя валидность веб-адресов.

ПОДГОТОВКА:
1. Убедитесь, что установлен Python 3.6+
2. Установите зависимости: pip install pandas openpyxl requests xlsxwriter

ИСПОЛЬЗОВАНИЕ:

Вариант 1 - Простой запуск (рекомендуется):
   python3 run_for_real_files.py

Вариант 2 - С указанием пути:
   python3 run_for_real_files.py "d:\001\Kursis\Kurs_from_Cursor\Организации\00"

Вариант 3 - Копирование файлов:
   1. Создайте папку: mkdir excel_files
   2. Скопируйте ваши .xlsx файлы в эту папку
   3. Запустите: python3 run_for_real_files.py excel_files

ЧТО ДЕЛАЕТ СКРИПТ:
✓ Читает все файлы .xlsx из указанной директории
✓ Автоматически определяет колонки с названиями организаций и сайтами
✓ Проверяет валидность веб-адресов (невалидные → "---")
✓ Удаляет дубликаты организаций, сохраняя записи с валидными сайтами
✓ Сохраняет результат в файл "ИТОГ.xlsx" в той же директории

ПРИМЕР РАБОТЫ:
Исходные файлы: ольгинка + 3км.xlsx, другой_файл.xlsx
Результат: ИТОГ.xlsx (объединенный файл без дубликатов)

ФАЙЛЫ В ПАКЕТЕ:
- run_for_real_files.py     - основной скрипт (запускайте этот)
- process_excel_files.py    - модуль обработки
- view_excel.py            - просмотр содержимого Excel файлов
- requirements.txt         - список зависимостей
- README.md               - подробная документация

ПОДДЕРЖКА:
При возникновении ошибок проверьте:
1. Корректность пути к файлам
2. Наличие файлов .xlsx в указанной директории
3. Права доступа к файлам
4. Установленные зависимости Python
