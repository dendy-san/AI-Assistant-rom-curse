# 📁 Как загрузить ваш архив в workspace

## Способ 1: Drag & Drop (Перетаскивание)
1. Откройте файловый менеджер на вашем компьютере
2. Найдите ваш архив (например, "организации.zip")
3. В Cursor откройте Explorer (боковая панель слева)
4. Перетащите архив в папку workspace

## Способ 2: Upload через интерфейс Cursor
1. В Explorer щелкните правой кнопкой по папке workspace
2. Выберите "Upload Files" или "Загрузить файлы"
3. Выберите ваш ZIP архив
4. Дождитесь завершения загрузки

## Способ 3: Через терминал (если файл уже в системе)
```bash
# Если архив на рабочем столе (Windows)
cp ~/Desktop/ваш_архив.zip /workspace/

# Если архив в папке Downloads
cp ~/Downloads/ваш_архив.zip /workspace/

# Или переместите из любой папки
mv /путь/к/вашему/архиву.zip /workspace/
```

## Способ 4: Создание архива из отдельных файлов
Если у вас есть отдельные Excel файлы:

1. Загрузите все .xlsx файлы в папку workspace/ваши_файлы/
2. Создайте архив командой:
```bash
python3 create_archive.py /workspace/ваши_файлы
```

## После загрузки архива:
```bash
# Проверьте что архив загружен
ls -la *.zip

# Запустите обработку
python3 universal_processor.py ваш_архив.zip
```

## Альтернативный способ - обработка без архива:
```bash
# Загрузите Excel файлы в папку ваши_файлы/
# Затем обработайте папку напрямую:
python3 universal_processor.py /workspace/ваши_файлы
```
